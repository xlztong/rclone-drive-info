Privacy policy

This policy describes the personal netcup-rclone utility operated by xlztong. Effective October 20, 2026.

Data accessed and purpose

After Google OAuth authorization, rclone accesses Google Drive file metadata, including names, IDs, sizes, and folder structure, and file contents needed to carry out the owner's requested operations. Its Drive permission enables reading and managing files, including creating copies, uploading, downloading, renaming, and deleting them.

Storage and retention

OAuth credentials and tokens are stored in a restricted configuration on the operator's privately managed server. Selected downloads remain on that server until the owner removes them. Copies created in Google Drive remain in the owner's Drive until removed. Operational logs may include file names, paths, and errors and are retained until the owner removes or rotates them.

Use and disclosure

The utility uses Drive data only for the owner's requested file operations. It does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. File operations communicate with Google Drive and, for downloads or uploads, the operator's server. The utility does not intentionally disclose Drive data to unrelated third parties.

Control and deletion

The owner can revoke the utility's access at Google Account connections. Revocation prevents further authorized access but does not remove files already copied or downloaded. The owner can delete those files and remove the server's saved OAuth configuration separately.

This website

These informational pages are hosted on GitHub Pages. They do not provide Google sign-in, receive Drive files or OAuth tokens, or embed analytics or tracking scripts. GitHub may process normal hosting request information under the GitHub Privacy Statement.

Contact and changes

For general privacy questions, contact the operator through the project's GitHub issues. This policy will be updated here if the utility's data handling changes.
